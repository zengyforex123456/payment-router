# 测试标准 — 四层金字塔·双阈值覆盖率·M3数据验收

> 层: L2 工程规范 | 版本: v1.0 | 合并: 02-test.md + 12-testing-standard.md（统一覆盖率阈值）

## Trigger

P3 测试阶段（由 `01-sdlc-lifecycle.md` 触发）/ "测试" "质量门禁" 关键字

## Input

- PRD 需求清单（每需求 ≥1 测试用例）
- 代码文件 + 端点清单
- 历史基线数据（L4 验收用）

## Action

### 四层测试金字塔

```
L1 原子能力 — 每个API/函数独立验证（输入→输出正确性）
L2 集成场景 — 端到端串联（≥2场景：快乐路径+异常路径）
L3 压力混沌 — 极端条件、并发风暴、故障注入
L4 数据验收 — 公式化判定（M3），不靠主观感觉
```

### L1: 原子能力测试

- 每个端点 ≥1 正常输入 + ≥1 异常输入
- 任一项失败 → 禁止进入 L2
- 反例：curl 返回 200 就算过 / 只测 Happy Path

### L2: 集成测试

| 场景 | 触发条件 | 验收标准 |
|------|---------|---------|
| A: Happy Path | 正常输入 | 最终状态符合预期 |
| B: 失败阻断 | 异常输入 | 阻断点正确，无残留 |
| C: 自动修复 | 失败→修复→重试 | 零人工干预完成 |
| D: 回滚 | 已发布→回退 | 版本号正确回退 |

### L3: 压力与混沌

| 测试类型 | 模拟方式 | 预期行为 |
|---------|---------|---------|
| 构建风暴 | N 次并发请求 | 排队不崩溃 |
| 节点故障 | kill 进程 | 任务迁移/标记失败 |
| 缓存污染 | 篡改缓存文件 | 检测不一致→回退 |
| 网络抖动 | 限制带宽 | 超时触发重试 |

规则：单机环境用序列化压力；集群环境并发数 ≥ 节点数；每种故障至少触发 1 次自愈。

### L4: M3 数据驱动验收

```
端到端时间 = CI_Duration + CD_Duration - Overlap(缓存预热)
```

| 维度 | 阈值 | 数据来源 |
|------|:---:|------|
| 速度 P95 | P95 < 目标 | 日志时间戳 |
| 成功率 | > 98% | 执行日志 |
| 自动化率 | < 5% 手动步骤 | 手动计数 |
| 回滚 RTO | < 3min | 端到端计时 |

### 覆盖率阈值（统一标准）

| 维度 | 新增代码 ≥ | 整体代码 最低 | 整体代码 目标 |
|------|:---:|:---:|:---:|
| 行覆盖率 | 80% | 60% | 80% |
| 关键路径 | 90% | 90% | 95% |
| 分支覆盖率 | 70% | 50% | 70% |
| API 端点覆盖率 | 100% | 100% | 100% |
| 场景覆盖率 | 80% | 60% | 80% |

整体代码 <60% → 阻塞上线。关键路径 (PR触发→CI→CD) ≥80%。

### 质量门禁 5 关

```
Unit(100%通过) → Integration(90%通过) → Security(0高危) → Performance(达标) → UX(≥90)
```

### 执行效率规则

1. 测试命令只运行一次，`tee` 保存输出
2. Read 读取输出分析结果
3. 有失败 → 一次性收集 → 批量修复 → 再跑一次
4. 整个 P3 最多运行 3 次测试命令
5. 禁止反复执行、单跑 `-t "name"`、每修一个跑一次

### UI 测试（强制）

- 视觉回归：Playwright screenshot
- 响应式：375/768/1440px
- 可访问性：axe-core 0 违规
- 交互：所有用户流程
- 性能：Lighthouse LCP<2.5s, CLS<0.1

## Output

- 测试报告（通过/失败/跳过）
- 覆盖率报告（% 每维度）
- Go/No-Go 决策

## Interface Contract

- **消费者**: `06-review-process.md`（P4 审查验证测试结果）、`01-sdlc-lifecycle.md`（P3 阶段引用）
- **依赖**: `11-prd-format.md`（PRD 需求驱动测试）
- **输出格式**: 测试报告 + 覆盖率 JSON
- **约定**: 新增代码行覆盖 ≥80%，整体 <60% 阻塞；P3 最多 3 次测试运行
